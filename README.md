# 飲料團購網站
使用 ASP.NET Core MVC 與 SQL Server 製作的課堂專案，協助主要團購者彙整飲料訂單、查看總金額，以及統計下一次訂購店家的投票結果。

## 使用技術
- C#
- ASP.NET Core MVC（.NET 8）
- HTML
- SQL Server
- Visual Studio

## 主要功能如下
### 登入與登出
- 透過指定的課堂測試帳號登入。
- 使用 Session 記錄登入狀態。
- 提供登出功能。

### 飲料訂購與訂單管理
- 從下拉選單選擇飲料，並可自行輸入金額。
- 新增訂單，顯示飲料品項、點餐人及金額。
- 修改既有訂單的飲料品項與金額。
- 取消訂單。
- 切換「顯示全部」與「我的點餐」。
- 提供訂單分頁，每頁顯示五筆。

### 團購金額統計
- 加總目前訂單金額。
- 以 500 元為免運門檻，顯示進度條與尚差金額。
- 訂單異動後，重新計算總金額與免運進度。

### 店家投票
- 提供四家飲料店的投票選項。
- 允許重複投票。
- 顯示各店累積票數與統計長條。

## 資料重設機制
課堂版本將每次成功登入視為新一輪團購的開始，
會清空指定的訂單與投票資料表，不保留歷史紀錄。
重新登入也會觸發重設。

目前使用共用資料表及指定測試帳號，
尚未提供多位團購者各自獨立管理團購的功能。

## 執行環境與限制
- Visual Studio，需安裝 ASP.NET 與網頁開發工作負載。
- .NET 8 SDK。
- SQL Server 及相容的資料表結構。

原始環境使用課程提供的資料庫。
本儲存庫不提供課程資料庫與連線帳密，因此下載後無法直接完整執行。
目前透過程式碼與示範影片呈現功能。

執行前須自行準備資料庫，
並透過本機 User Secrets 設定
`ConnectionStrings:DefaultConnection`。
